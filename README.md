# Migration PoC Generator (hackathon26)

RDBMS-to-MongoDB migration PoC agent for the MongoDB Agentic Platform.

## Layout

- `project-config.yaml` — project-level memory settings
- `agents/rdbms-migration-poc-agent/` — runnable agent (`agentic dev up` from that directory)

See `agents/rdbms-migration-poc-agent/README.md` and `DEMO.md` for setup, Grove/LLM env, Postgres seed, and Playground demo.
